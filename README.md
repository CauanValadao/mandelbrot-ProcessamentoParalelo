# mandelbrot-ProcessamentoParalelo
Implementação e análise de desempenho do cálculo do conjunto de Mandelbrot com OpenMP, desenvolvida para a disciplina de Processamento Paralelo da UESC, avaliando speedup, eficiência, balanceamento de carga, escalabilidade forte e fraca e impacto do tamanho do chunk

Nota de Transparência sobre o Uso de IA: Declaro que este projeto contou com o auxílio das ferramentas de IA exclusivamente para as tarefas de: Auxílio na construção de funções de suporte: comparar_matrizes(), 
calcular_estatisticas(), pode_usar_simetria(); Auxílio na depuração (debugging) de blocos específicos de código; Geração de scripts base para automação de testes de desempenho e geração de gráficos; Estruturação inicial de ideias e revisão bibliográfica. Como autores, atestamos que revisamos, testamos e validamos criticamente todo o conteúdo gerado, assumindo total e exclusiva responsabilidade pela correção lógica do código, precisão dos relatórios de desempenho e integridade acadêmica do material entregue.
